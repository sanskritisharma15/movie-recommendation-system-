How It Works

About ScreenScout

ScreenScout is a content-based movie recommendation system built for Task-03 — it suggests movies by analyzing genre and thematic similarity, not user ratings.

📊

1. Data Representation

Each movie is tagged with a genre and a short description built from genre-specific keywords (action, romance, horror, comedy, etc).

🔢

2. TF-IDF Vectorization

Descriptions are converted into numeric vectors using Term Frequency–Inverse Document Frequency, capturing how distinctive each word is.

📐

3. Cosine Similarity

The angle between every pair of movie vectors is measured — smaller angle means more similar content.

🎯

4. Top-N Recommendation

When you pick a movie, the system ranks all others by similarity score and returns the top 5 matches.
